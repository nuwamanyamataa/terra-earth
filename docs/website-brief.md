### Features
- Click-to-call, WhatsApp, mailto links, and a Google Map.
- Netlify Forms with a honeypot spam field and a thank-you message.
- Breadcrumbs, project filters without page reloads, FAQ accordions, and gentle fade-ins that respect reduced-motion settings.
- **Search:** a unique title and description on each page, LocalBusiness structured data, Open Graph share image (1200×630), sitemap.xml and robots.txt. Register on Google Search Console and create a Google Business Profile.
- **Accessibility:** WCAG 2.1 AA, at least 16 px text, 44 px tap targets, visible keyboard focus.
- **Speed:** WebP images, hero image under 200 KB, no sliders, and Lighthouse scores of 90+ on mobile. It must work well on a mid-range Android phone over 3G/4G.
- **Not in version 1:** blog, payments, client login, multiple languages.

### Tech stack
- Astro (static output), plain CSS variables and minimal vanilla JavaScript.
- Services and projects as Markdown files in `src/content/`.
- Netlify hosting, deployed from a private GitHub repository, with DNS for terra-earth.co.ug pointed to Netlify.
- Breakpoints at 640, 960 and 1200 px.
- Folder layout: `public/{images,logo,docs}`, `src/{styles,layouts,components,content,pages}`, plus CLAUDE.md and SPEC.md.
